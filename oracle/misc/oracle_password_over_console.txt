SQL*Plus Konsolunda Özel Karakterli Şifreler
=============================================

Bazı karakterler (!, *, $, ', ", @, vb.) shell tarafından özel anlamlar taşıyabilir 
ve doğrudan komut satırında sorun yaratabilir. Bu durumlar için çeşitli çözümler vardır.

1. TEKTIRNAK İÇİNDE ÇIFT TIRNAK (Önerilir)
-------------------------------------------
Şifre: abC123456!!**
Komut:
  sqlplus 'sys/"abC123456!!**"@TESTDB_SRC' as sysdba

Avantaj: Basit ve çoğu durumda çalışır.


2. ÇİFT TIRNAK İÇİNDE TEKTIRNAK
---------------------------------
Şifre: abC123456"pass
Komut:
  sqlplus "sys/'abC123456\"pass'@TESTDB_SRC" as sysdba

Avantaj: Şifreyi çift tırnak ile sarmak.


3. KARIŞIK KARAKTER DURUMU (Tektirnak + Çifttirnak)
----------------------------------------------------
Şifre: ab"C'123456!!**
Komut:
  sqlplus 'sys/"'"'"'ab"C'"'"'123456!!**"'"'"'@TESTDB_SRC' as sysdba

Açıklama:
  'sys/"'      → sys/" (tektırnak içinde)
  "'"          → tek tırnak (çift tırnak içinde)
  'ab"C'       → ab"C (tektırnak içinde)
  "'"          → tek tırnak (çift tırnak içinde)  
  '123456!!**"'"'"'@TESTDB_SRC' → devamı


4. KAÇIŞ KARÖKTERİ KULLANMA (bash/sh)
---------------------------------------
Şifre: ab"C'123456!!**
Komut:
  sqlplus 'sys/"ab\"C'"'"'123456!!**"@TESTDB_SRC' as sysdba


5. ENVIRONMENT VARİYABLİ ÇÖZÜM (En Güvenli)
---------------------------------------------
# Script içinde:
export ORACLE_USER=sys
export ORACLE_PASSWORD='ab"C'"'"'123456!!**'
export ORACLE_SID=TESTDB_SRC

sqlplus "$ORACLE_USER"/"$ORACLE_PASSWORD"@"$ORACLE_SID" as sysdba

Avantaj: Şifre komut satırında görünmez, log dosyasına yazılmaz.


6. WALLET/CREDENTIALS DOSYASI (Üretim için tavsiye)
------------------------------------------------------
Oracle Wallet kullanarak şifreleri güvenli bir şekilde depolayabilirsiniz.
Bkz: Oracle Secure External Password Store (OSEPS)


ÖNERİLER
=========
- Terminal güvenliği: Komutu bash_history'ye yazılmamış şekilde çalıştırın
  $ history -n; sqlplus ...
  
- En güvenli yol: Wallet veya environment variable kullanmak
- En praktik yol: Tektırnak ve çifttırnak kombinasyonu
- Tırnak sorunlarından kaçınmak için şifreyi alphanumerik karakterlerle oluşturun
